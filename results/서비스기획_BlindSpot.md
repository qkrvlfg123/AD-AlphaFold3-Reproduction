# BlindSpot

AlphaFold3, Boltz-2 기반 미스센스 변이 구조 예측 감별력 검정 플랫폼
*Mutation Detectability Assessment Platform for AlphaFold3 · Boltz-2*

같은 서열을 반복 예측해 모델 고유의 재현 변동성을 음성 대조군으로 확보하고, 야생형과 변이형 사이의 구조 편차와 결합 인터페이스 편차가 이 변동을 넘는지 비모수 검정(라벨 순열검정)으로 판정해, 해당 예측을 근거로 쓸 수 있는지 미리 선별하는 시스템의 기획서임.

- 근거 데이터: Yao et al. (2024) *Cell Genomics* 4:100700 재현 결과
- 저장소: https://github.com/qkrvlfg123/AD-AlphaFold3-Reproduction
- 데모: https://qkrvlfg123.github.io/AD-AlphaFold3-Reproduction/app/
- 이 문서의 p 값은 현재 검정(라벨 순열검정)으로 `results/`의 CSV에서 다시 계산한 값임. 문서를 처음 쓸 때는 Mann-Whitney U 검정을 썼고 그때의 값은 "이전 검정" 열에 남김.
- 6~7절은 설계안임. 현재 앱에 구현된 범위는 9절에 있음.

# 1. 서비스 정의

## 1.1 한 문장

"이 변이에 대해 구조 예측을 증거로 쓸 수 있는지"를 판정함.

## 1.2 정의

같은 조건의 반복 예측으로 모델 재현 변동성(intra-condition variability)을 음성 대조군으로 확보하고, 야생형과 변이형 사이의 구조적 편차가 이를 넘는지 비모수 검정으로 판정해, 해당 예측의 증거 사용 적합성을 보고함.

## 1.3 성격

발견(discovery) 도구가 아니라 선별(triage) 도구임. 변이의 생물학적 효과를 규명하지 않으며, 구조 예측이라는 방법이 해당 변이에 적용 가능한지를 판정함.

# 2. 존재 근거

## 2.1 문제가 실제로 있다는 근거

동료심사를 거쳐 게재된 논문이 본문 Figure 4B에 CD33 R69G의 구조적 변화를 대표 사례로 제시함. 같은 조건으로 재현한 결과는 아래와 같음.

| 항목 | 값 |
|---|---|
| 같은 조건 반복 예측 편차 (n = 20쌍) | 0.124 Å (범위 0.045~0.186) |
| 야생형과 변이형 사이 편차 (n = 25쌍) | 0.120 Å |
| Δ | −0.004 Å |
| 라벨 순열검정, 단측 (전수 126분할) | p = 0.65 |
| 이전 검정 (Mann-Whitney U, 단측) | p = 0.54 |

귀무가설 기각 실패임. 게재 논문의 대표 그림이 이 검정을 통과하지 못함.

## 2.2 원인: 모델의 구조적 특성

| 원인 | 근거 |
|---|---|
| AlphaFold는 구조 붕괴 변이 데이터베이스로 학습되지 않아 야생형과 상동 서열 기반으로 예측함 | Buel & Walters (2022) *Nat Struct Mol Biol* |
| Boltz-2 affinity는 결합부위 변이에 둔감하며, 타겟을 바꿔도 분류가 유지되는 사례가 있음 | Bret et al. (2026) *J Chem Inf Model* |
| 확산 기반 생성 모델의 비결정적 출력. 같은 입력에 서로 다른 구조가 나옴 | 모델 아키텍처 |

개별 사용자의 오류가 아니라 방법의 구조적 한계임.

## 2.3 기존 신뢰도 지표는 변이 감별력을 보장하지 않음

이 서비스의 중심 논거임. 현행 지표(pLDDT, pTM, ipTM)는 예측 구조의 정확도를 추정할 뿐이며, 변이가 반영되었는지와는 다른 값을 잼. 이 저장소의 결과가 그 예임.

| 사례 | 모델 보고 신뢰도 | 변이 감별 (순열검정) | 이전 검정 p |
|---|---|---|---|
| CD33 R69G | 도메인 pLDDT 97.3, 변이부위 pLDDT 96.7~97.1, pTM 0.59~0.60 | 변동성 내 (p = 0.65) | 0.54 |
| TREM2 R62H + Aβ42 | ipTM 0.851 (통상 0.8 이상이면 신뢰), complex pLDDT 0.856 | 변동성 내 (p = 0.80) | 0.30 |

신뢰도가 높은 조건에서도 변이 효과가 검출되지 않음. pLDDT 97은 해당 위치 구조에 대한 확신을 뜻할 뿐 변이가 반영되었다는 뜻이 아님.

## 2.4 공백: 현행 도구는 이 값을 제공하지 않음

| 도구 | 제공 지표 | 변이 감별력 보고 |
|---|---|---|
| AlphaFold Server (AF3) | 구조, pLDDT, pTM | 없음 |
| Boltz-2 | 복합체, ipTM, affinity | 없음 |
| AlphaMissense | 병원성 점수 | 없음 (구조 편차를 산출하지 않음) |
| FoldX, Rosetta | ΔΔG | 없음 (예측 모델 변동성을 반영하지 않음) |

## 2.5 검정 없이 썼을 때의 비용

구조적 편차는 기전 서술의 근거로 쓰임(논문, 특허 명세, 과제 제안서, 타겟 우선순위 결정). 그 근거가 모델 재현 변동성이었다면 후속 실험 자원이 낭비됨.

## 2.6 시의성

AF3 웹서버와 Boltz-2(MIT)가 공개되어 변이 구조 예측의 진입장벽이 낮아짐. 사용량이 늘수록 검정 없는 사용도 늘어남.

# 3. 서비스 범위

## 3.1 답하는 것

| 대상 | 출력 |
|---|---|
| 이 예측을 구조적 변화의 근거로 쓸 수 있는지 | 재현 변동성 초과 또는 변동성 내, p, 효과크기 |
| 모델이 이 변이를 감별할 수 있는지 | 재현 변동성 대비 편차 비 |
| 계산을 더 진행할지 실험으로 넘어갈지 | 판정에 따른 분기 |
| 여러 변이 중 구조 예측이 유효한 것 | 증거 사용 가능성 기준 정렬 |

## 3.2 답하지 않는 것 (명시적 경계)

| 대상 | 제공 |
|---|---|
| 변이의 병원성 여부 | 제공하지 않음 |
| 변이가 단백질 기능을 바꾸는지 여부 | 제공하지 않음 |
| 변이가 손상시키는 대상 (접힘, 결합면, 안정성, 활성부위) | 제공하지 않음 |
| 약물 결합 부위의 변화 (druggability) | 제공하지 않음 |
| 실제 구조의 불변 여부 | 제공하지 않음. 미검출은 무변화와 다름 |

## 3.3 미검출 판정의 해석: 세 가능성

미검출은 다음 세 경우를 구분하지 못함. 이 서비스의 명시적 한계임.

| | 내용 |
|---|---|
| (a) | 접힘이 실제로 변하지 않음. 모델이 정확히 산출함 |
| (b) | 접힘이 변하지만 모델이 포착하지 못함. 모델 한계 |
| (c) | 변이 효과가 접힘이 아닌 다른 층위에 있음 (결합, 발현, 수송, 안정성, PTM) |

따라서 판정 문구는 "구조 변화 없음"이 아니라 "이 예측으로 판단 불가"로 냄.

## 3.4 정렬 결과의 의미

산출되는 순위는 증거 사용 가능성 순위이며 생물학적 중요도 순위가 아님.

| 사례 | 재현 변동성 | 변이 편차 | 비 |
|---|---|---|---|
| PILRA R78G | 0.100 Å | 0.995 Å | 9.97× |
| TREM2 R62H | 0.168 Å | 0.257 Å | 1.53× |
| CD33 R69G | 0.124 Å | 0.120 Å | 0.97× |

CD33 R69G는 원논문이 AD 위험 증가로 지목한 변이이나 이 지표에서는 최하위임. 모델이 감별하지 못한다는 뜻이며 생물학적 중요도가 낮다는 뜻이 아님.

## 6.1 [화면: HOME]

요약 설명

1. 서비스 정의 헤더: "구조 예측 모델의 변이 감별력 사전 검정 플랫폼"
2. 문제 제시 패널: 같은 서열을 반복 예측한 구조 2개를 나란히 놓아 재현 변동성이 있음을 바로 보여줌
3. 검정 원리 도식: 음성 대조군 구성 → 처리군과 대비 → 비모수 검정
4. 근거 문헌 카드: Buel & Walters 2022, Bret et al. 2026 (모델 한계) / Yao et al. 2024 (재현 대상), DOI 링크
5. 논거 표: pLDDT 97, ipTM 0.85 조건에서의 미검출 사례 (2.3절 표)
6. 사례 진입: `CD33 R69G`, `PILRA R78G`, `TREM2 R62H`, `TREM2+Aβ42`
7. 서비스 경계 고지: "이 서비스는 변이의 생물학적 효과를 규명하지 않으며 예측의 증거 사용 적합성만 판정함" (상시 노출)
8. 저장소 링크: 스크립트(`src/` 12종)와 예측 구조 60개 공개

## 6.2 [화면: 변이 입력 및 검증]

요약 설명

1. UniProt accession 입력: 조회 후 단백질명, 길이, 도메인 경계, 신호펩타이드 구간 표시
2. 변이 표기 입력: 전구체(precursor) 번호 기준임을 명시. 형식 `[야생형][위치][변이형]`
3. 잔기 대조 검증: 해당 위치의 정본 잔기를 조회해 입력값과 대조
   - 일치하면 진행 활성화
   - 불일치하면 실제 잔기를 표시하고 진행 차단 (예: PILRA 78번 입력 시 "정본 서열의 78번은 Arg")
4. 예측 구간 선택: 전장 또는 도메인 절단. 도메인을 고르면 UniProt 주석 경계를 기본값으로 제안
5. 앙상블 파라미터: 샘플 수 n (기본 5), 시드 (기본 1, 기록됨)
6. 서열 대조 뷰: 야생형과 변이형을 나란히 놓고 다른 잔기 1개만 강조
7. 입력 파일 내려받기: AlphaFold Server 업로드용 JSON, Boltz-2 YAML 동시 생성

설계 근거: 3번 검증은 재현 과정에서 PILRA 변이 방향 오류(문헌 표기 `G78R`, 정본 기준 `R78G`)를 미리 막은 로직임.

## 6.3 [화면: 구조 축 감별력 검정]

요약 설명

1. 3D 오버레이 (Mol*): 야생형과 변이형을 겹쳐 표시, 변이 잔기는 stick 표시
2. `재현 앙상블 표시` 토글 (이 화면의 주 기능으로 설계)
   - 켜면 같은 서열로 산출된 구조 n개를 동시에 표시
   - 재현 변동성의 크기를 눈으로 볼 수 있게 함
3. 변이 부위 확대: 해당 잔기로 시점 이동, 8 Å 반경 강조
4. 분포 도표: 음성 대조군과 처리군 편차 분포를 같은 축에 표시, 중앙값 표기
5. 판정 카드 (7절 사양)
6. 측정 조건 패널: 정렬 구간, 컷오프, 검정 방식, 시드, 샘플 수
7. 원자료 내려받기: 구조 파일, 편차 쌍 CSV

---

## 6.4 [화면: 결합 축 감별력 검정]

요약 설명

1. 결합 상대 입력: 펩타이드 서열 또는 리간드 SMILES (사례 기본값: Aβ42, APP 672~713)
2. 복합체 3D 뷰어 (Mol*): 사슬별 색 구분, 인터페이스 잔기 강조
3. ipTM 분포 도표: 구조 축과 같은 형식. 현재 앱은 야생형, 변이형 원시 분포가 아니라 ipTM 쌍 차이의 음성 대조군과 처리군 분포를 그림
4. 판정 카드: 쌍 차이 중앙값, 범위, 비, p, 판정. 원시 ipTM 중앙값을 함께 표기
5. 지표 정의 고지
   - ipTM은 결합 자유에너지가 아니라 인터페이스 예측 신뢰도 지표임
   - Boltz-2 affinity head는 small-molecule 전용이며 펩타이드에 적용되지 않음
6. 관련 실험 문헌: 해당 단백질에 대해 보고된 결합 실험 (TREM2: Zhao 2018, Zhong 2018, Yeh 2016)
7. 해석 비제공 고지: 결합 변화 여부에 대한 판단은 제공하지 않음

---

## 6.5 [화면: 통합 리포트]

요약 설명

1. 두 축 판정 요약: 구조 축, 결합 축 각각의 통계량과 판정
2. 종합 판정 문구: 규칙 기반 생성
   - 두 축 모두 검출: "두 축 모두에서 변이 효과가 재현 변동성을 초과"
   - 두 축 모두 미검출: "이 예측으로 변이 효과를 판단할 수 없음"
   - 축별로 다르면 분리해 보고
   - 현재 앱은 문구 대신 2×2 매트릭스(구조 축 × 결합 축)에 사례를 배치함
3. 문헌 대조 패널: 보고된 실험 결과와 모델 판정을 나란히 표시
   - 불일치하면 "문헌은 효과를 보고하나 이 모델은 미검출"로 표기
4. 재현 정보: 도구, 버전, 시드, 샘플 수, 실행일시, 정렬 조건
5. 일괄 내려받기: 구조, CSV, 도표 ZIP
6. 인용 정보: 이 서비스와 근거 문헌의 인용 형식
7. 경계 재고지: 해석 비제공 문구 반복

## 7.1 변이 효과 미검출: 구조 축

```
CD33 · R69G  (rs2455069)
판정: 재현 변동성 내 (모델 감별력 미달)

    같은 조건 반복 예측 편차     0.124 Å   [0.045~0.186]   n = 20
    야생형, 변이형 사이 편차      0.120 Å                    n = 25
    Δ                          −0.004 Å

  라벨 순열검정, 단측, α = 0.05, 전수 126분할    p = 0.65
  (이전 검정: Mann-Whitney U, 단측             p = 0.54)
  → 귀무가설 기각 실패.
     변이에 기인한 구조 편차가 모델 재현 변동성과
     통계적으로 구분되지 않음.

  ※ 구조 불변을 뜻하지 않으며 이 모델의 감별 한계를 뜻함.
```

## 7.2 변이 효과 검출 (효과크기 제한적): 구조 축

```
TREM2 · R62H  (rs143332484)
판정: 재현 변동성 초과 (효과크기 작음)

  국소 RMSD (Cα, 8 Å)
    같은 조건 반복 예측 편차     0.168 Å   [0.069~1.250]   n = 20
    야생형, 변이형 사이 편차      0.257 Å                    n = 25
    Δ                          +0.089 Å

  라벨 순열검정, 단측, 전수 126분할             p = 0.0079
  (이 표본 크기에서 도달 가능한 최소 p = 1/126)
  (이전 검정: Mann-Whitney U, 단측             p = 5.4×10⁻³)
  → 귀무가설 기각.

  주의: Δ 0.089 Å은 앱이 기준으로 쓰는 1.5 Å의 약 6% 수준으로
     구조적 유의성은 제한적.
     도메인 전체 RMSD로 검정하면 p = 0.64로 기각되지 않음.
     UniProt Q9NZC2는 이 변이를 "does not affect protein
     structure"로 주석하며 효과를 리간드 결합으로 귀속 (기록).
```

| 구조 예측 실행 | 구현하지 않음 | GPU 필요. 예측 1건 10~30분, AF Server 하루 30건 제한 (기록) |

설계는 임의 입력을 전제하며, 검증, 서열 생성, 파일 내려받기, 업로드 후 검정 단계는 임의 accession에 대해 동작함. 예측 실행만 사전 산출 결과(구조 3건, 결합 2건)로 대신함. 연산 자원 제약 때문이며 설계상 제약은 아님.

6절 설계안 중 현재 앱에 없는 것

- 6.1의 문제 제시 패널(반복 예측 구조 2개 병치)은 없음. 근거 문헌 카드와 논거 표는 홈이 아니라 방법론 화면에 있음
- 6.3의 `재현 앙상블 표시` 토글, 변이 부위 확대, 원자료 내려받기
- 6.4의 결합 상대 입력. 결합 인터페이스 검증 화면은 TREM2 + Aβ42 전용임. PILRA + NPDC1은 리포트 화면에 수치만 나옴
- 6.5의 종합 판정 문구 생성, 일괄 내려받기(ZIP), 인용 정보, 실행일시 표기

# 11. 사례 데이터

| 사례 | 축 | 구조 수 | 판정 | p (순열검정) | 이전 검정 p (Mann-Whitney) |
|---|---|---|---|---|---|
| PILRA R78G | 구조 | 10 | 변동성 초과 | 0.0079 | 6×10⁻⁹ |
| TREM2 R62H | 구조 | 10 | 변동성 초과 (효과크기 작음, 국소 지표 기준) | 0.0079 | 5.4×10⁻³ |
| CD33 R69G | 구조 | 10 | 변동성 내 | 0.65 | 0.54 |
| TREM2 R62H + Aβ42 | 결합 | 30 | 변동성 내 | 0.80 | 0.30 |
| PILRA R78G + NPDC1 | 결합 | 20 | 변동성 내 | 0.97 | 0.85 |

- 0.0079는 조건당 모델 5개(전수 분할 126개)에서 도달 가능한 최소 p임.
- 판정은 검정을 바꾸기 전후로 다섯 사례 모두 같음.
- PILRA + NPDC1은 이 문서를 처음 쓴 뒤에 추가한 사례임. ipTM 수치만 있고 복합체 구조 파일은 저장소에 없음.

CD33 R69G는 원논문 본문 Figure 4B의 대표 사례임. 본문에 대표로 실린 그림이 변동성 내 판정을 받는다는 점이 이 서비스가 필요한 이유의 예시임.

PILRA R78G는 야생형과 변이형의 실험 결정구조가 모두 등록되어 있어(`4NFB` 78R, `3WUZ` 78G) 앞으로 예측값을 실측과 대조할 수 있는 기준점이 됨.
