> 미스센스 변이 구조 예측 감별력 검정 플랫폼
>
> 동일 서열을 반복 예측해 모델 고유의 재현 변동성을 음성 대조군으로 확보하고,
> 야생형과 변이형 간 구조 및 결합 인터페이스 편차가 이를 초과하는지 비모수 검정으로 판정하여,
> 해당 예측을 근거로 사용할 수 있는지 사전에 선별하는 시스템
>
> BlindSpot · 근거 데이터 Yao et al. (2024) *Cell Genomics* 4:100700 재현 실측

설명

- 앞의 재현 결과를 도구로 만든 부분을 소개함.
- 서비스 이름은 BlindSpot임. 구조 예측 모델에는 사각지대가 있음. 어떤 변이는 모델이 보지 못하는데, 현재는 그것을 확인할 방법이 없음. 이 도구는 그 사각지대를 먼저 찾음.
- 방식: 같은 서열을 여러 번 예측하면 모델은 매번 조금씩 다른 구조를 냄. 그 변동의 크기가 기준선임. 변이를 넣어 생긴 차이가 그 기준선을 넘는지 통계적으로 판정함.

소요 시간: 40초

## Slide 02. 서비스 존재 근거

화면 (이미지 파일은 `svc_01_타이틀.png`)

문제

- 구조 예측 모델은 확률적 생성 모델이므로 같은 서열에도 비결정적 출력을 냄
- 따라서 관측된 편차가 변이 때문인지 모델 변동 때문인지 구분되지 않음

실측 근거

- 게재 논문이 본문 Figure 4B에 CD33 R69G의 구조 변화를 대표 사례로 제시
- 같은 조건 재현 결과 귀무가설 기각 실패. 슬라이드 표기 p = 0.54, 현재 값 p = 0.65

신뢰도가 높은 조건에서도 변이가 검출되지 않음

| 사례 | 모델 보고 신뢰도 | 변이 감별 (슬라이드 표기) | 현재 값 |
|---|---|---|---|
| CD33 R69G | 도메인 pLDDT 97.3, pTM 0.60 | 변동성 내, p 0.54 | 변동성 내, p 0.65 |
| TREM2 R62H + Aβ42 | ipTM 0.851, complex pLDDT 0.856 | 변동성 내, p 0.30 | 변동성 내, p 0.80 |

선행 연구

- Buel & Walters (2022) *Nat Struct Mol Biol*: AF2는 구조 붕괴 변이 DB로 학습되지 않음
- Bret et al. (2026) *JCIM*: Boltz-2 affinity의 결합부위 변이 둔감성
- 두 문헌 모두 한계를 지적했고 정량 기준은 제시하지 않음

설명

- 이런 도구가 필요한 이유부터 설명함.
- 구조 예측 모델은 확률적으로 구조를 생성함. 같은 서열을 넣어도 매번 결과가 다름. 그래서 야생형과 변이형을 겹쳐 보고 차이를 발견해도, 그것이 변이 때문인지 모델이 원래 흔들리는 것인지 알 수 없음.
- 추정이 아니라 재현 결과임. 동료심사를 거쳐 게재된 논문이 본문 대표 그림으로 실은 CD33 사례가 재현 결과 p = 0.65로 기준선을 넘지 못함(이전 검정에서는 0.54).
- 표의 두 사례 모두 모델이 보고한 신뢰도는 높음(pLDDT 97, ipTM 0.85). 그런데도 변이는 검출되지 않음. pLDDT 97은 그 위치의 구조를 확신한다는 뜻이지 변이를 반영했다는 뜻이 아님. 이 둘이 구분 없이 쓰이는 경우가 있음.
- 관련 한계는 이미 문헌에 보고되어 있음. AlphaFold2가 미스센스 변이에 둔감하다는 지적도, Boltz-2가 결합부위 변이에 둔감하다는 보고도 있음. 다만 두 문헌 모두 지적에 그쳤고 정량 기준은 없음. 슬라이드에 든 현행 도구(AlphaFold Server, Boltz-2, AlphaMissense, FoldX) 중 변이 감별력을 따로 보고하는 것은 없음.

소요 시간: 1분 30초

전달 방향

- "논문이 틀렸다"가 아니라 "현행 도구에 빠진 기능이 있다"로 전달함.
- CD33 사례는 문제가 실제로 있음을 보이는 근거로만 쓰고, 논문 비판으로 넓히지 않음.

## Slide 03. 서비스 파이프라인

화면 (이미지 파일은 `svc_02_존재근거.png`)

6단계 흐름

| | 단계 | 기술 (슬라이드 표기) |
|---|---|---|
| 1 | 서열 확보, 변이 검증 | UniProt REST |
| 2 | 구조 앙상블 생성 (사용자 수행) | AlphaFold Server, Boltz-2 |
| 3 | 음성 대조군 구성 | Horn 중첩 |
| 4 | 감별력 검정 | Mann-Whitney U. 현재는 라벨 순열검정 |
| 5 | 결합 인터페이스 확장 | Boltz-2, ipTM |
| 6 | 판정 리포트 | Mol*, SVG |

검정 설계

| 항목 | 내용 |
|---|---|
| H₀ | 야생형과 변이형 사이 편차 = 같은 조건 반복 예측의 변동 |
| H₁ | 변이형 편차가 재현 변동성을 초과함 |
| 음성 대조군 | 같은 서열의 모델 쌍. 변이가 없으므로 관측 편차는 모두 모델 변동 |
| 검정 | 슬라이드 표기는 Mann-Whitney U, α = 0.05. 현재는 라벨 순열검정, 단측, α = 0.05 |
| 통제 변수 | 같은 도구, 같은 구간, 시드 고정, 같은 샘플 수 |

구현 현황: 슬라이드 표는 4개 기능 구현, 1개 미구현(구조 예측 실행, GPU 필요)으로 적혀 있음. 6단계 기준으로는 5개 단계가 브라우저에서 동작하고 1개 단계(구조 예측)가 외부임

설명

- 파이프라인은 6단계임.
- 첫째, UniProt에서 서열을 가져와 변이를 검증함. 둘째, 구조를 여러 번 예측함. 셋째, 같은 서열끼리의 쌍을 음성 대조군으로 묶음. 넷째, 야생형과 변이형 쌍을 그 대조군과 비교해 검정함. 다섯째, 복합체가 있으면 같은 절차를 결합 인터페이스에도 적용함. 여섯째, 판정을 리포트로 냄.
- 가장 중요한 것은 세 번째 단계임. 음성 대조군에는 변이가 없음. 그러므로 거기서 관측되는 편차는 모두 모델 자체의 변동임. 이것이 "구조가 변했다"를 판정할 기준선이 됨. 논문에는 이 기준선이 없었음.
- 여섯 단계 중 다섯 개는 브라우저에서 동작함. 두 번째 단계인 구조 예측만 GPU가 필요해서 사용자가 AlphaFold Server에서 직접 수행함. 무료이고 하루 30건까지 가능함 (기록).

소요 시간: 1분 20초

## Slide 05. 화면: 분석 `svc_05_화면_분석.png`

화면: 분석 화면 스크린샷 + 콜아웃 7개

설명

- 이 화면은 임의의 단백질에 대해 동작함.
- UniProt accession을 입력하면 REST API를 직접 호출해 단백질명과 길이, 신호펩타이드와 도메인 경계를 가져옴. 변이 표기를 넣으면 해당 위치의 실제 잔기와 대조함.
- 이 도구의 첫 번째 기능임. 예를 들어 PILRA 변이를 문헌 표기대로 G78R로 입력하면 진행이 차단됨. UniProt 정본 서열의 78번은 이미 아르기닌이기 때문임. 그리고 올바른 표기인 R78G를 제시함. 재현 과정에서 이 오류를 미리 막았던 검증 로직을 옮긴 것임.
- 검증을 통과하면 야생형과 변이형 서열을 나란히 보여주고 다른 글자 하나만 강조함. AlphaFold Server용 JSON, Boltz-2용 YAML, FASTA를 내려받을 수 있음.
- 화면 아래쪽은 나중에 추가한 부분임. 파일을 내려받아 AlphaFold Server에서 예측한 뒤 결과 ZIP을 여기에 올리면 브라우저가 구조를 직접 읽어 편차를 계산하고 검정함. 파일은 서버로 전송되지 않음.

소요 시간: 1분 20초

## Slide 07. 화면: 결합 인터페이스 검증 `svc_07_화면_결합인터페이스.png`

화면: 결합 검증 화면 스크린샷 + 콜아웃 5개

설명

- 구조 축만으로 판단하기 어려우면 결합 축을 봄. 실험 문헌은 TREM2 R62H가 아밀로이드 베타 결합을 떨어뜨린다고 보고함. 그래서 Boltz-2로 TREM2와 아밀로이드 베타 42의 복합체를 예측하고, 구조 검증과 같은 절차를 적용함.
- 현재 결과는 p = 0.80임. ipTM 쌍 차이의 중앙값이 음성 대조군 0.046, 처리군 0.043으로 비가 0.95×임. 슬라이드를 만들 때는 두 군의 ipTM을 직접 비교한 Mann-Whitney 양측 검정으로 p = 0.30이었음.
- 원시 ipTM 중앙값은 야생형 0.851, 변이형 0.824인데, 야생형 안에서도 0.56에서 0.90까지 변동함. 두 군의 차이가 이 변동 안에 있음.
- 여기서 쓰는 ipTM은 결합 자유에너지가 아니라 인터페이스 예측 신뢰도 지표임. Boltz-2의 결합 친화도 기능은 저분자 전용이라 펩타이드인 아밀로이드 베타에는 적용되지 않음. 따라서 이 화면은 결합력 수치를 산출하지 않음. 화면에도 그렇게 표기함.

소요 시간: 1분

## Slide 08. 화면: 리포트 / 방법론 `svc_08_화면_리포트방법론.png`

화면: 리포트 화면 스크린샷 + 콜아웃 3개 + 방법론 화면 설명. 이미지는 2×2 종합 판정 매트릭스를 추가하기 전의 화면임

설명

- 리포트는 전 사례의 기준 변동, 측정 편차, 비, p 값, 판정을 한 표로 정리함. 이 표의 통계량은 원자료에서 브라우저가 다시 계산한 값임. 현재 앱은 표 위에 구조 축 × 결합 축 2×2 매트릭스를 함께 보여줌.
- 문헌 대조 항목이 있음. Zhao 등의 2018년 보고는 이 변이가 결합을 감소시킨다고 하는데 이 모델은 감별하지 못함. 그럴 때 문헌은 효과를 보고하나 모델은 감별하지 못했다고 표기하고, 계산이 아닌 실험적 접근이 필요한 사례로 분류함.
- 방법론 화면에는 가설과 대조군 설계, 존재 근거, 서비스 범위, 한계를 담음.
- 정리하면 이 도구가 답하는 것은 하나임. "이 변이에 대해 구조 예측을 증거로 쓸 수 있는지"임. 변이가 무엇을 하는지는 답하지 않음. 그 이상을 주장하지 않는 것이 이 도구의 설계 원칙임.

소요 시간: 1분

## Slide 09. 활용 기술 스택 `svc_09_기술스택.png`

화면

- 계층 구조: 데이터 → 예측 → 계산(자체 구현) → 표현 → 배포
- 구성 요소 및 라이선스: 외부 3(UniProt REST API, AlphaFold Server, Boltz-2), 라이브러리 2(Mol*, JSZip), 자체 구현 4(mmCIF 파서, 구조 중첩과 RMSD, Mann-Whitney U, 분포 도표)
- 재현 파이프라인: Python 3, PyMOL 3.1.0, 스크립트 10종 (슬라이드 표기. 현재 `src/`는 12종)

설명

- 서열과 주석은 UniProt REST API에서 실시간으로 가져옴. RCSB PDB는 참조 결정구조(4NFB, 3WUZ, 5UD7, 5UD8)의 출처이며 앱이 실시간으로 불러오지는 않음. 예측은 AlphaFold Server와 Boltz-2를 씀.
- 가운데 계산 계층이 이 서비스에서 직접 만든 부분임. 외부 라이브러리를 쓰지 않고 구현함. mmCIF 파서, Horn 사원수법 최적 중첩과 Jacobi 고유분해, 국소 RMSD, 그리고 검정임.
- 검정은 슬라이드를 만들 때 Mann-Whitney U(정규근사, 연속성 보정, 동순위 보정)였고, 현재는 라벨 순열검정(전수 열거 또는 고정 시드 표본 20,000회)임. Mann-Whitney U 구현은 순열을 돌릴 수 없을 때의 대체값용으로 남아 있음.
- 표현 계층에서 3D는 Mol*을 쓰고 분포 도표는 SVG로 직접 그림. 차트 라이브러리를 쓰지 않음.
- 배포는 GitHub Pages 정적 호스팅임. 빌드 과정도 서버도 없음. 업로드한 파일은 클라이언트에서만 처리되고 외부로 전송되지 않음.
- AlphaFold Server는 비영리 한정 라이선스임. 그래서 상업 전개를 고려해 예측 단계를 모델 교체가 가능한 구조로 설계함. 업로드 경로는 MIT 라이선스인 Boltz-2의 출력도 읽도록 되어 있음.

소요 시간: 1분 10초

# 시연 시나리오 (선택, 2분)

Slide 05에서 진행함. 데모 주소를 미리 열어 둠.

| | 동작 | 보여줄 것 |
|---|---|---|
| 1 | `Q9UKJ1` + `G78R` 입력 | 진행 차단. "78번은 이미 Arg, R78G 인지 확인" |
| 2 | `R78G`로 수정 | 통과, 서열 생성, dbSNP 자동 매칭 |
| 3 | 구조 검증 탭 → `CD33` | 두 분포가 겹침, p 0.65 |
| 4 | `PILRA`로 전환 | 분리됨, p 0.0079 (전수 126분할에서 도달 가능한 최소 p) |

임의 단백질을 요청받을 경우 (기록. UniProt 조회 결과에 따른 값이라 저장소 안에서는 다시 확인할 수 없음)

- `P04637`(p53) `R175H`, `P42212`(GFP, 해파리) `S65T`가 통과 사례임.
- `P01308`(인슐린) `H24R`은 차단됨. 전구체 번호 기준으로 24번이 Ala이기 때문임. 번호 체계 차이를 보여주는 예시로 쓸 수 있음.

딥링크

```
?s=s2&acc=Q9UKJ1&mut=G78R     차단 사례
?s=s2&acc=P04637&mut=R175H    p53 통과
?s=s3                          구조 검증 결과
```
