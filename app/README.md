# BlindSpot

AlphaFold3, Boltz-2 기반 미스센스 변이 구조 예측 감별력 검정 웹 애플리케이션

같은 서열을 반복 예측해 모델 고유의 재현 변동성을 음성 대조군으로 확보하고, 야생형과 변이형 사이의 구조 편차와 결합 인터페이스 편차가 이 변동을 넘는지 라벨 순열검정으로 판정함. 해당 예측을 근거로 쓸 수 있는지 미리 선별하는 용도임.

배포본: https://qkrvlfg123.github.io/AD-AlphaFold3-Reproduction/app/

---

## 하는 일

구조 예측 모델은 야생형과 변이형에 대해 각각 구조를 내지만, 확률적 생성 모델이라 같은 서열에도 출력이 매번 조금씩 다름. 관측된 구조 편차가 변이 때문인지 모델 재현 변동성인지는 구조 한 쌍으로 구분되지 않음.

BlindSpot은 같은 조건의 반복 예측을 음성 대조군으로 삼아 이 구분을 통계적으로 판정함.

- 판정하는 것: 이 예측을 구조적 변화의 근거로 쓸 수 있는지 여부
- 판정하지 않는 것: 변이의 병원성, 기능 변화, 생물학적 의미

## 실행

```bash
cd app
python3 -m http.server 8899
# http://localhost:8899
```

- `file://`로 직접 열면 CORS 때문에 UniProt 조회가 차단됨. HTTP 서버가 필요함.
- 배포본(GitHub Pages)은 HTTPS라 이 제약이 없음.
- 설치할 의존성과 빌드 과정이 없음. 정적 파일만으로 동작함. Mol*과 JSZip은 CDN에서 불러옴.

## 구현 현황

| 기능 | 상태 | 구현 |
|---|---|---|
| UniProt 조회, 잔기 대조 검증 | 구현됨. 임의 accession 가능 | `app.js`의 `fetchUniProt`, `validateMut` |
| 변이 서열 생성, 도메인 자동 절단 | 구현됨 | `buildSequences` |

| 순열을 돌릴 수 없을 때의 대체값 | 구현됨 | `mannWhitneyU`. 정규근사, 연속성 보정, 동순위 보정. 쌍 행렬에 빈 칸이 있을 때만 p로 쓰임 |
| 분포 도표 | 구현됨 | `drawStrip`. SVG 직접 생성 |
| 3D 구조 뷰어 | 구현됨 | Mol*. WebGL이 없으면 사전 렌더 이미지로 대체 |
| 2×2 종합 판정 매트릭스 | 구현됨. 리포트 화면(`?s=s5`) | `renderVerdictMatrix` |
| 결과 ZIP 업로드 후 편차 계산과 검정 | 구현됨. 임의 단백질 가능, 구조 축만 | `analyze.js`. mmCIF 파싱, Horn 중첩, 국소 RMSD, `permutationP` |
| 구조 예측 실행 | 구현하지 않음 | GPU 필요. 사용자가 AlphaFold Server에서 실행한 뒤 결과를 업로드함 |

### 작업 흐름

```
1. 앱      UniProt 조회 → 잔기 검증 → 서열 생성 → 입력 파일 내려받기
2. 사용자   AlphaFold Server에서 예측 (작업당 모델 5개)
3. 앱      결과 ZIP 업로드 → mmCIF 파싱 → 중첩 → 국소 RMSD → 검정 → 판정
```

- GPU가 필요한 2번만 외부에서 하고 나머지는 브라우저에서 처리함.
- 업로드한 파일은 서버로 전송되지 않음. 모두 클라이언트에서 처리함.
- AlphaFold Server의 무료 사용과 하루 30건 한도는 작업 당시 확인한 조건임 (기록).

### 편차 계산 (`analyze.js`)

| 단계 | 방법 |
|---|---|
| mmCIF 파싱 | `atom_site` 루프에서 Cα 추출. B-factor를 pLDDT로 사용 |
| 정렬 구간 | 양쪽 모두 pLDDT 70 이상인 잔기. 무질서 구간이 정렬을 흐리는 것을 막는 규칙임. 20잔기 미만이면 공통 잔기 전체를 사용 |
| 최적 중첩 | Horn 사원수법 (4×4 대칭행렬 Jacobi 고유분해) |
| 국소 RMSD | 변이 잔기 8 Å 이내 Cα. 재정렬 없이 측정 |
| 기준 반복 | 같은 그룹 안의 모델 쌍 |
| 변이 비교 | 그룹 간 모델 쌍 |
| 검정 | `app.js`의 `splitPairs`, `permutationP`를 그대로 사용. 쌍이 하나라도 비면 `mannWhitneyU` 값으로 대체 |

수록 사례(`src/rmsd_analysis.py`)는 알려진 도메인 경계로 정렬했고, 업로드 경로는 pLDDT 기준을 씀. 임의 단백질에는 도메인 주석이 없을 수 있기 때문임. 그래서 절대값은 다를 수 있음.

CD33 R69G로 두 경로를 비교한 값 (두 경로 모두 라벨 순열검정, 전수 126분할)

| 경로 | 기준 반복 | 변이 비교 | 비 | p | 판정 |
|---|---|---|---|---|---|
| 사전 산출 (코드) | 0.124 | 0.120 | 0.97× | 0.65 | 재현 변동성 내 |
| 업로드 경로 (기록) | 0.194 | 0.180 | 0.93× | 0.72 | 재현 변동성 내 |

업로드 경로 값은 작업 당시 기록이며 저장소에 이 값을 다시 만드는 스크립트는 없음.

## 서열 검증

`Q9UKJ1` + `G78R`을 입력하면 앱이 "서열 불일치"를 표시하고 진행을 막음. 안내 내용은 입력한 변이의 기준 잔기(Gly)가 야생형 서열 78번 잔기(Arg)와 다르다는 것, 표기 방향이 반대일 수 있으니 `R78G`인지 확인하라는 것임.

- 문헌은 PILRA 변이를 보통 `G78R`로 표기하지만 UniProt 정본의 78번은 이미 Arg이고, rs1859788은 R→G로 등재되어 있음. 논문 Figure S5(a) 주석도 `Arginine > Glycine`임.
- 재현 과정에서 이 오류를 막았던 `src/sequences.py`의 `assert` 규칙을 옮긴 것임.

## 임의 accession 입력 시 동작

수록 사례가 아닌 단백질도 조회, 검증, 파일 생성까지 동작함. 사전 산출 결과는 수록 사례(구조 3건, 결합 2건)에만 있고, 그 밖의 입력에는 다른 사례의 결과를 표시하지 않음.

예시: `P36969` (GPX4_HUMAN, 197 aa) (기록. UniProt 조회 결과에 따른 값이라 저장소 안에서는 다시 확인할 수 없음)

| 단계 | 동작 |
|---|---|
| 조회 | `GPX4_HUMAN · 197 aa`, 도메인 주석 없음 |
| `R152H` 입력 | 차단. 152번은 Lys (canonical 기준) |
| `U73C` 입력 | 통과. 73번이 Sec(U)로 일치 |
| 도메인 절단 | 해당 위치를 포함하는 도메인 주석이 없어 전장으로 대체 |
| 비표준 잔기 | 경고. Sec(U)는 AlphaFold와 Boltz-2가 처리하지 못하므로 치환이 필요함 |
| 구조 검증 실행 | 사전 산출 결과가 없다고 안내. 입력 파일을 내려받아 직접 예측하도록 안내 |

딥링크로 같은 상태를 열 수 있음: `?s=s2&acc=P36969&mut=U73C`

## 통계 산출

`permutationP()`. 라벨 순열검정이며 두 축이 같은 설계를 씀.

| 항목 | 내용 |
|---|---|
| 음성 대조군 | 같은 조건 안의 쌍 (같은 서열을 반복 예측한 모델끼리의 차이) |
| 처리군 | 조건 간의 쌍 (야생형 모델 × 변이형 모델) |
| 통계량 | median(처리군 쌍) − median(음성 대조군 쌍) |
| 검정 | 두 축 모두 단측, α = 0.05 |
| 방식 | 분할 수가 20,000 이하이면 전수 열거, 초과하면 고정 시드(1) 표본 20,000회 |

순열검정을 쓰는 이유

- 쌍은 서로 독립이 아님. 같은 구조가 여러 쌍에 재사용되므로 Mann-Whitney의 p는 과소평가됨(PILRA 구조 축은 6×10⁻⁹에서 0.0079로 바뀜). 라벨을 뒤섞어 얻은 경험 분포로 교정함.
- 판정은 다섯 사례 모두 바뀌지 않았음.

구현상의 특징

- 원자료 CSV를 브라우저가 읽어 계산하므로 리포트, 구조 검증, 결합 검증 화면의 통계값은 코드에 고정되어 있지 않음. 홈 화면 사례 카드와 방법론 화면 표의 p는 `index.html`에 적어 둔 값임.
- 고정 시드를 쓰므로 다시 실행해도 같은 값이 나옴.
- `src/detectability.py`가 같은 알고리즘과 같은 PRNG(mulberry32)를 씀. `app.js`의 검정 함수를 node로 실행해 비교하면 다섯 사례 모두 두 구현의 p가 같은 값으로 나옴 (코드).

## 탑재 사례

| 사례 | 축 | 판정 | 처리군/음성 대조군 비 | p |
|---|---|---|---|---|
| PILRA R78G | 구조 | 재현 변동성 초과 | 9.97× | 0.0079 |
| TREM2 R62H | 구조 | 재현 변동성 초과 (효과크기 작음, 국소 지표 기준) | 1.53× | 0.0079 |
| CD33 R69G | 구조 | 재현 변동성 내 | 0.97× | 0.65 |
| TREM2 R62H + Aβ42 | 인터페이스 | 재현 변동성 내 | 0.95× | 0.80 |
| PILRA R78G + NPDC1 | 인터페이스 | 재현 변동성 내 | 0.80× | 0.97 |

- `0.0079`는 조건당 모델 5개(전수 분할 126개)에서 도달 가능한 최소 p임. 더 작은 p를 얻으려면 모델 수를 늘려야 함.
- CD33 R69G는 원논문(Yao et al. 2024)이 본문 Figure 4B에 대표로 실은 사례임.
- 홈 화면에는 이 중 4건(PILRA, TREM2, CD33 구조와 TREM2 + Aβ42)이 카드로 있음. PILRA + NPDC1은 리포트 화면에서 볼 수 있음.

## 한계

- 예측 대 예측 비교이며 실험적 검증은 없음
- 조건당 모델 5개에서는 p가 0.0079 아래로 내려갈 수 없음(전수 분할 126개)
- "재현 변동성 내"는 구조가 변하지 않았다는 뜻이 아니라 모델의 감별 한계를 뜻함
- ipTM은 결합 자유에너지가 아니라 인터페이스 예측 신뢰도 지표임
- PILRA 결합은 시알산 매개이나 Boltz-2 단백질-단백질 예측에는 글리칸이 없음. 미감별의 원인이 모델의 감별 한계인지 글리칸 부재인지 이 결과만으로는 구분할 수 없음 (추정)
- 산출되는 정렬은 증거 사용 가능성 순위이며 생물학적 중요도 순위가 아님
- 업로드 경로는 구조 축만 지원함. 결합 인터페이스 검증 화면은 TREM2 + Aβ42 전용임
